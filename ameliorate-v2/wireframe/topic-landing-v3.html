This is a prototype of an app for integrating disputed knowledge about uncertain problems.

It’s entirely based on this ontology.md, using that as the data structure and visualizing some features that are enabled by the structure. This UX-design.md describes some of the prototype’s design in text.

Nothing here is functional. It’s hard-coded to the ontology’s “Build a wall” example, viewed as danny — new to the topic, hasn’t scored anything yet; the scores shown are alice’s, bob’s and casey’s.

v3 — changes since v2 (“focus and inspect”)
  1. Colour key — a legend (bottom-left of the diagram) explaining the colours: red = reduce / “bad”, gray = no change, blue = increase / “good”; a diagonal sweep means scorers disagree.
  2. Claim inspector — selecting a node (or edge) pops up its implied claim in ontology wording, each scorer’s score, and pros/cons calculated from its causal edges.
  3. Focus mode — selecting a node/edge fades everything unrelated and emphasises the selection’s direct causal neighbours.
