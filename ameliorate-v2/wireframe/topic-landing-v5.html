ameliorate-v2 prototype /

This is a prototype of an app for integrating disputed knowledge about uncertain problems.

It’s entirely based on this ontology.md, using that as the data structure and visualizing some features that are enabled by the structure. This UX-design.md describes some of the prototype’s design in text.

Nothing here is functional. The data is generated from the ontology’s “Build a wall” example, viewed as danny — new to the topic, hasn’t scored anything yet; the scores shown are alice’s, bob’s and casey’s.

v5 — changes since v4
  1. The numbers are calculated, not hand-derived. Scores, rankings, question priorities, pros/cons and the tradeoffs table all come from ameliorate-v2/scripts reading the example, and are pasted in as one bundle.
  2. The diagram shows the concepts ranked nearest the topic — the same ranking Highlights uses, so the two panes agree about what matters.
  3. Dashed edges stand in for relations that run through concepts the diagram isn’t showing, so a branch never reads as unrelated when it is merely hidden.
  4. Question priorities now chain through the causal map to the topic, so a question about a concept is ranked by how much of the topic runs through it.
  5. Criteria can appear in Highlights; they reach the topic through fulfils, which the hand-built list had no way to follow.
