This is a prototype of an app for integrating disputed knowledge about uncertain problems.

It’s entirely based on this ontology.md, using that as the data structure and visualizing some features that are enabled by the structure. This UX-design.md describes some of the prototype’s design in text.

Nothing here is functional. It’s hard-coded to the ontology’s “Build a wall” example, viewed as danny — new to the topic, hasn’t scored anything yet; the scores shown are alice’s, bob’s and casey’s.

v1 — the first wireframe, so nothing to compare against yet. What it establishes:
  1. Split panes: an agenda pane (left, ranked text) and a structure pane (right, visuals).
  2. Agenda sections: Topic (description + “tour”), Guiding questions, Hottest details with filter pills.
  3. Structure pane: a collapsible generated summary strip above a causal diagram of the top-10 hottest items.
  4. Score distributions drawn as one colour band per scorer on node and edge-label borders.
  5. Clicking a pill in the summary or agenda highlights the matching node/edge in the diagram, and vice versa.
